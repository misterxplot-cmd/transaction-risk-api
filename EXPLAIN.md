# Как разобраться в API

`schema.py` описывает входные поля и ограничения. Pydantic превращает JSON в проверенный объект до вызова модели.

`service.py` создаёт DataFrame с фиксированным порядком полей, вызывает `predict_proba` и формирует ответ. Обучение не происходит при каждом запросе.

`main.py` загружает модель один раз в lifespan приложения. `/health` отвечает о состоянии процесса, `/ready` — о готовности модели. Поэтому при отсутствующем файле процесс работает, но прогноз недоступен.

`train_demo.py` позволяет запустить сервис без чужого датасета. Генератор использует искусственную формулу меток. Режим synthetic_demo обязательно возвращается пользователю.
